# Sun Associates — Premium Digital Business Card Website

This version was redesigned around the main goal: **make Sun Associates memorable and make booking a consultation easy**.

## Improvements in this version
- Much larger, easier-to-read typography
- More use of the full screen and page width
- Stronger visual hierarchy
- Cinematic high-resolution visual assets included locally in `assets/`
- Consultation CTA appears in the navigation, hero, a floating action card, and the main contact section
- Simplified into a focused interactive digital business card rather than an overloaded traditional law-firm website
- Responsive desktop and mobile layout
- Smooth reveal interactions and premium hover effects

## Run
Open `index.html` directly, or run a local server:

```bash
npx serve .
```

## Before production
Replace placeholder legal details, contact information and practice-area descriptions with verified information from the real Sun Associates firm.
