# Sun Associates — Premium Interactive Website

A complete responsive single-page law firm website inspired by Apple-style design principles:
- Premium editorial typography
- Cinematic courtroom-inspired visuals
- Interactive reveal animations
- Scale of justice and gavel visual elements
- Practice areas, approach, statistics, insights and consultation form
- Mobile responsive layout

## Run locally
Simply open `index.html` in a browser.

For the best experience, use a local server, for example:
```bash
npx serve .
```

## Important before production
Replace the placeholder contact details, statistics, article dates and practice-area claims with verified information from the real firm.
